 ASHFALL - Rise From The Ashes
Run it

```bash
pip install -r requirements.txt
python main.py
```

**Controls**
- `A` / `D` or Arrow keys - move
- `SPACE` / `W` - jump
- `J` or `ENTER` - attack (melee swing, or fires an arrow if you're holding the bow)
- `E` - open a nearby chest (locked chests cost coins)
- `ESC` - pause
